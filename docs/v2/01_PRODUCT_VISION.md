# 01_PRODUCT_VISION.md

> CampusCue V2 产品定义。基于 V1 已确认事实与总根提示词第三章重述，供后续所有 Milestone 对齐。

## 一句话定位

面向大学生的**校园事务 AI Agent 平台**：把 QQ 群里的作业、考试、比赛、活动、通知自动变成带截止时间的任务，并提供 AI 助手、日历、提醒与 WebUI。

## 目标用户

- 大学生（核心用户，每天使用）
- 校园班级 / 社团群的管理者（作业收集、活动通知）

## 核心问题

1. 校园群消息每天大量产生，作业 / 考试 / 截止通知淹没在闲聊里。
2. 学生需要跨群汇总"我最近要做什么"，以及"什么时候截止"。
3. 现有工具（群公告、备忘录、记事本）不能自动从群聊抽取结构化任务。

## 用户故事（V2 目标）

- 作为学生，我在 QQ 群里看到"高数第三章作业周五晚上 12 点前交学习通"，CampusCue 自动把它变成任务，我打开 WebUI 就能看到。
- 作为学生，我问"我这周有什么事情？"，AI 助手通过真实任务数据回答我（不是编的）。
- 作为学生，截止前我收到提醒，避免漏交。
- 作为学生，我在手机上（390px）能完成查看 / 完成 / 新建任务的核心操作。

## 产品三核心（按优先级）

1. **校园事务管理**（第一核心）—— 任务、来源、提取、去重、日历、提醒。
2. **AI 助手**（第二核心）—— Agent + Tool 访问真实任务数据。
3. **QQ 自动信息入口**（第三核心）—— NapCat + OneBot v11 自动接入。

## 非目标（V2 明确不做，见 `29 不需要的功能` 与各 Milestone 范围）

- 泛聊天机器人 / 万能 Bot Framework
- 插件市场 / 多平台（Telegram/Discord 等）
- 知识库 / RAG / 复杂 Agent 编排（MCP、SubAgent、Skills、Computer Use）
- 复杂 RBAC / 微服务 / 分布式
- 开发者控制台 / 服务器管理面板

## 产品气质

学生每天会用的校园事务工具。视觉重点是**信息、任务、截止时间、来源、状态、日历、消息**，不是"AI 感"。正式 WebUI 禁 Emoji、禁营销腔（见总根提示词第十一、十二章）。
