# ADR-006：TaskService 是唯一任务创建/变更入口

- **Status**：Accepted（M0）
- **Date**：2026-08-09
- **Context**：V1 有两条建任务路径（API 和 LLM 工具），dedup 只在一处生效，导致重复创建（B03）。
- **Decision**：API / Agent Tool / Extraction Pipeline 全部经 `TaskService.create/update/complete/dismiss/delete`。去重、提醒联动、Realtime 通知全部收敛在 Service。
- **Alternatives**：各入口自行查重（拒绝：V1 已证明会漏）。
- **Reason**：业务不变式（dedup、reminder 联动）只维护一处。
- **Consequences**：新增任务来源只需实现一个 Service 调用。
