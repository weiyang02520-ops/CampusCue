# ADR-005：第一版无 Plugin System

- **Status**：Accepted（M0）
- **Date**：2026-08-09
- **Context**：AstrBot Plugin System 复杂度极高（discover/load/reload/hot reload/handler registry/lifecycle），CampusCue 无真实第三方扩展需求。
- **Decision**：第一版用明确 Handler + ToolRegistry，不实现 Plugin System。出现真实扩展需求时再设计 Extension API（写入 NEXT_TASKS）。
- **Alternatives**：直接上插件系统（拒绝：YAGNI）。
- **Reason**：垂直产品不需要通用扩展市场。
- **Consequences**：功能演进通过代码内 Handler 扩展；未来加插件系统时以 ToolRegistry 为扩展点。
