# ADR-008：Provider 请求实体承载工具链路

- **Status**：Accepted（M0）
- **Date**：2026-08-09
- **Context**：AstrBot 把 func_tool + tool_calls_result 做进 ProviderRequest，Provider 不感知 Agent 循环（研究确认）。
- **Decision**：V2 LLMRequest 携带 tools schema + tool_results 回填；OpenAICompatibleProvider 只负责"带工具调用一次对话"，Agent 循环在 runtime 层。
- **Alternatives**：Provider 内置 agent 循环（拒绝：职责混杂）。
- **Reason**：Provider 可单独测试/替换。
- **Consequences**：Agent runtime 的防呆（max_steps/重复调用/超时）与 Provider 分离。
