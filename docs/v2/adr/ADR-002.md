# ADR-002：Database 是唯一业务事实源

- **Status**：Accepted（M0）
- **Date**：2026-08-09
- **Context**：V1 中 AstrBot cron 表是提醒的事实源之一，SSE 状态与 DB 有同步问题（B02）。
- **Decision**：tasks/sources/extractions/reminders/provider_configs/settings 全部以 SQLite 为事实源。Runtime cache、APScheduler jobs、Pinia store、SSE 载荷全部为派生状态，任何时刻可由 DB 重建。
- **Alternatives**：以内存事件流为事实源（拒绝：重启即失）。
- **Reason**：恢复能力（重启/备份/多端一致）只依赖 DB。
- **Consequences**：所有变更必须落库后再通知；SSE 只做通知不做状态存储。
