# ADR-003：Realtime 传输不是状态源

- **Status**：Accepted（M0）
- **Date**：2026-08-09
- **Context**：V1 SSE 断连后状态不同步（B02）、日志洪水（B01）。
- **Decision**：SSE（`/api/v1/stream`）仅推送变更通知（task.* / reminder.* / extraction.* / connection.*）；前端收到通知按需 REST 刷新；断线重连后全量 REST 补拉 canonical state。连接生命周期：cleanup 完整、指数退避、日志限频。
- **Alternatives**：SSE 承载业务状态（拒绝：断线即丢）。
- **Reason**：REST 可重放、可缓存、可调试；SSE 只是加速。
- **Consequences**：前端任何页面打开时先 REST 拉全量，再订阅增量。
