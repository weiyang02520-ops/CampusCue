# ADR-010：时区显式注入，前端不硬编码偏移

- **Status**：Accepted（M0）
- **Date**：2026-08-09
- **Context**：V1 时区硬编码（CAMPUS_TZ 常量 + 前端 +8h，B12）。
- **Decision**：TimeNormalizer / ReminderScheduler 全部显式接收 timezone 与 current_time；API 返回 aware ISO 时间；前端用浏览器本地时区渲染，不硬编码偏移。
- **Alternatives**：全局固定 Asia/Shanghai（拒绝：profile.timezone 已存在却未打通）。
- **Reason**：可测试性（固定时钟）与多时区正确性。
- **Consequences**：所有时间边界测试需注入固定时钟/时区。
