# ADR-004：无 AstrBot Runtime 依赖

- **Status**：Accepted（M0）
- **Date**：2026-08-09
- **Context**：V1 全部跑在 AstrBot Runtime 上（main.py 用 InitialLoader），是 V2 重新立项的原因。
- **Decision**：V2 零依赖 AstrBot。`import astrbot` 任何形式 → Anti-AstrBot Gate 扫描 FAIL。V2 在无 AstrBot 的环境必须能完整运行。
- **Alternatives**：继续 fork AstrBot（拒绝：根本问题不解决）。
- **Reason**：独立性、可控性、可维护性。
- **Consequences**：AstrBot 仅作为 REFERENCE IMPLEMENTATION 研究（docs/v2/03、19）；所有能力自研。
