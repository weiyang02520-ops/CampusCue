# ADR-009：本地优先，LAN 需重新设计安全模型

- **Status**：Accepted（M0）
- **Date**：2026-08-09
- **Context**：V1 默认 loopback；AstrBot dashboard 有整套 JWT 认证。
- **Decision**：V2 默认仅监听 127.0.0.1（WebUI/API/OneBot WS）。允许 LAN 必须重新设计安全模型（token 认证 + 传输保护），M5 定稿。OneBot WS 入口校验本机来源。
- **Alternatives**：直接上完整认证（拒绝：本地使用为主，YAGNI）。
- **Reason**：平衡安全与简单。
- **Consequences**：多设备访问需等 M5 安全模型。
