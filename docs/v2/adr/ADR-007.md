# ADR-007：Reminder 调度可完全由 DB 重建

- **Status**：Accepted（M0）
- **Date**：2026-08-09
- **Context**：V1 已验证"cron 表只是缓存、启动时从 tasks 全量重建"（reminders.py resync_all）。
- **Decision**：reminders 表为事实，APScheduler job 为派生；启动 resync；任何操作幂等（job_id 固定 + replace_existing）。
- **Alternatives**：持久化 job（拒绝：状态残留、重启脏数据）。
- **Reason**：DB 推导调度表永远一致。
- **Consequences**：错过执行时间的提醒不补发（设计行为）；崩溃恢复天然正确。
