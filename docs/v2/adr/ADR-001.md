# ADR-001：OneBot 协议不泄漏进 Domain

- **Status**：Accepted（M0）
- **Date**：2026-08-09
- **Context**：V1 中 OneBot 原始 JSON 由 AstrBot 适配器消化，但 CampusCue star 仍需读 `event.message_obj.raw_message` 取字段；V2 无 AstrBot，必须自行定义边界。
- **Decision**：`adapters/onebot/converter.py` 在 Adapter 边界内把 OneBot v11 JSON 转换为 `CampusEvent`；业务层（Router/Pipeline/Agent/Service）只见 CampusEvent。OneBot 原始载荷仅存 `metadata.raw` 供调试，不进业务逻辑。
- **Alternatives**：让业务层直接消费 OneBot JSON（拒绝：未来加平台或换协议时业务层全改）。
- **Reason**：平台差异收敛在唯一 Adapter；converter 为纯函数可单测。
- **Consequences**：新增消息段类型只需改 converter + 段模型；OneBot 升级不影响上层。
